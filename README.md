# Kinesthesia pod viewer

Live Web Bluetooth viewer for the Kinesthesia shoe pod.

Open https://nabilrashidd.github.io/kine-viewer/ in Chrome or Edge on a computer, or in the
Bluefy browser on iPhone/iPad (Safari has no Web Bluetooth).

Published copy of `viewer/gait_viewer_12.html` from the pod's main repository; edit it there.

`two.html` is the two-feet viewer (left and right pods together), a copy of `viewer/two_feet.html`.
